## Reading these numbers

- These results describe performance on **synthetic data generated by this project**. They do not predict performance on real telemetry, which has messier seasonality, drift and anomaly shapes.
- Per-minute recall is lower than event recall because a detector only needs to flag part of an episode for an engineer to notice it, and gradual anomalies (such as memory leaks) start below any threshold.
- A flagged minute is a prompt for investigation, not a confirmed incident.
- How the settings were chosen: Isolation Forest hyperparameters were picked on a separate validation dataset (seed 1000). The threshold rule (Q3 + 3 x IQR of training scores) replaced a 99.5th-percentile rule after the percentile proved sensitive to anomalies in the training data. That change was made during development while test results were visible, so treat these numbers as somewhat optimistic.
